# Portfolio v7 - Phan Anh Tài

## Sản phẩm này là gì?
Website giới thiệu bản thân, thông tin sinh viên và các dự án học tập, thiết kế dành cho nhà tuyển dụng thực tập[cite: 7, 12].

## Demo
https://phananhtai.github.io/portfolio-v7/[cite: 4, 12]

## Tính năng
- Xem thông tin giới thiệu cá nhân (Họ tên, MSSV, Lớp, Học phần FIT4014)[cite: 2].
- Danh sách dự án cá nhân nổi bật (Portfolio v7, Hệ thống Quản lý Phần mềm) có kèm thẻ tag công nghệ[cite: 2].
- Phần liên hệ trực tiếp qua Email và liên kết GitHub Repository[cite: 2].

## Cách mở
1. Mở trình duyệt web bất kỳ (Chrome, Edge, Firefox...).
2. Dán hoặc truy cập vào URL Demo ở trên.
3. Nhấn vào các mục trên thanh menu (`Giới thiệu`, `Dự án`, `Liên hệ`) để xem nội dung chi tiết hoặc cuộn trang trực tiếp[cite: 7, 12].

## Cấu trúc thư mục
- `index.html`: Trang chủ chính của website[cite: 4]
- `css/style.css`: File định dạng phong cách giao diện[cite: 4]
- `assets/`: Thư mục chứa tài nguyên hình ảnh[cite: 4]
- `docs/`: Thư mục chứa tài liệu minh chứng (`evidence-index.md`, `AI_LOG.md`)[cite: 4]
